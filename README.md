# VitexOS
Vitex OS — высокопроизводительное кастомное x86-ядро и операционная система с нуля на C/C++. Включает динамический аллокатор, сетевой стек, TinyGL GUI в стиле Windows, init-систему и пакетный менеджер VSR с трансляцией стороннего софта. Полный путь от голого железа до собственной экосистемы без лишнего bloatware. 🚀
